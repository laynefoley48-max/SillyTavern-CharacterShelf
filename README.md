# 角色卡册 · Character Shelf

适用于 TauriTavern（TT）与 SillyTavern 的私人角色卡浏览扩展。

## 从 Git 安装

扩展管理器 → 从 Git 安装 → 粘贴下面的公开仓库地址：

https://github.com/laynefoley48-max/SillyTavern-CharacterShelf

已安装旧版本时，在扩展管理器中更新本扩展，然后刷新 TT。

## v0.2.0

- 独立角色卡册：列表预览和头像网格双视图，默认按导入时间（date_added）从新到旧排序。
- 列表头像缩小并置于左上，右侧显示角色名、私人备注摘要及酒馆原生标签；不展示设为「角色卡隐藏」的标签。
- 搜索支持角色名、备注以及原生标签名。
- 点击任意角色卡首先弹出完整备注，底部两个按钮为「编辑备注」和「跳转卡面」；不会直接跳转聊天。
- 三套配色：跟随酒馆、日间模式（浅灰白）、灰色夜间模式（中性碳灰）。可从窗口顶端直接切换并记忆。
- 「跟随酒馆」通过 SillyTavern 的 SmartTheme CSS 变量实现，无需复制当前主题配色，并会跟随主题变量变化。
- 私人备注使用 extension_settings.characterShelf.notes 保存，按角色头像文件名区分，另提供 JSON 备份与恢复。

## 使用

重载后打开右侧角色列表，点击顶部的书本图标。进入角色卡册后可以切换列表/头像模式，选择排序、配色并搜索。
点击一张卡片会弹出备注预览；点击「编辑备注」后可输入任意长度文字并保存；只有点击「跳转卡面」才会打开该角色。

## 数据注意

私人备注不改动角色卡原有的作者备注、人物设定和世界书，也不作为提示词发送给 AI。
原生角色标签只读取并展示，不在本插件内改动。
清空酒馆设置或重置 TT 前，请先点击「备份备注」，再通过「恢复备注」导入备份。导出的单独角色卡文件不含本插件私人备注。
