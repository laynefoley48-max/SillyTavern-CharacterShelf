# 角色备注 · Character Notes

适用于 TauriTavern (TT) 与 SillyTavern (ST) 的角色卡私人备注与浏览扩展。

## 从 Git 安装或更新

扩展管理器 → 从 Git 安装 → 粘贴：

https://github.com/laynefoley48-max/SillyTavern-CharacterShelf

已安装的用户请直接在扩展管理器内更新并刷新酒馆，无须卸载重装。仓库名称暂时保留 CharacterShelf，避免改变已安装扩展目录；插件界面名称为「角色备注」。

## v0.7.0

- **大角色库分页**：新增「每页显示」20 / 30 / 50 / 100 张，默认 30 张；窗口底部可上一页、下一页或直接跳页。搜索、原生标签匹配、筛选及排序仍针对全部角色卡；只生成当前页头像与卡片节点，翻页时清理其他页的节点缓存。
- **小窗拖动更顺滑**：改用 `transform: translate3d()` 位移，并通过 `requestAnimationFrame` 合并手指移动事件；只在拖动结束后写回最终坐标和保存位置，拖动期间临时启用合成层提示，不改变原有窗口外观。
- **侧边书本点击调整**：书本半隐藏、窗口未打开时，点击一次会让书本探出并同时打开窗口；如果窗口已经打开，第一次点击只让书本探出，第二次点击才会关闭窗口。探出后 3 秒无操作仍自动缩回，拖离侧边则不再自动收回。
- **兼容性**：沿用原有备注存储键、备份格式、筛选排序方式及手机输入框独立滚动。每页数量会保存在扩展设置中。

## v0.5.0
- **默认非全屏**：打开角色备注显示紧凑悬浮窗口，四周保留可见的聊天区域；底层聊天不会因半透明遮罩变暗。点右上角全屏图标可切换全屏，再点恢复小窗口。
- **可拖动**：非全屏时按住窗口顶部标题栏拖动；详情标题栏和编辑标题也可用于拖动。位置会保存，窗口随手机屏幕和窗口尺寸变化自动限制边界。
- **书本悬浮按钮**：在扩展设置中开启后，窗口打开时书本按钮仍显示在窗口上层。点书本打开，再点书本只隐藏窗口；下次打开保留搜索、筛选、滚动位置、当前详情，以及编辑框里未保存的文本。拖动按钮本身可调整位置。
- **空备注不占文字位置**：未填写备注的角色列表不再显示“还没有备注，点击查看并添加”，但仍可点击角色卡添加备注。
- **兼容性**：布局针对窄屏手机（包括横屏和虚拟键盘）作了约束；仍需在不同 TT/ST 设备上实际验证视觉和交互。

## 隐私与数据存储

本插件不实现向第三方服务器主动上传角色卡、私人备注或浏览行为的功能。插件使用酒馆自己的 extension_settings 保存数据，保存位置取决于本地或远程酒馆运行方式，也可能受到用户额外配置的同步/备份机制影响。

私人备注继续保存于 extension_settings.characterShelf.notes，按角色头像文件名标识。升级到 v0.4.0 不修改备注存储键、不清空旧备注；旧 CharacterShelfBackup JSON 备份格式仍可以导入。

插件不会改动角色卡原始作者备注、人物设定或世界书，也不会将私人备注作为提示词发送给 AI。单独导出的角色卡文件不包含插件私人备注。重置酒馆、清空设置之前，请从扩展设置中导出 JSON 备份。
