# 角色备注 · Character Notes

适用于 **TauriTavern (TT) / SillyTavern (ST)** 的独立角色卡私人备注插件。

## Git 安装与更新

在扩展管理器 → 从 Git 安装，粘贴以下公开仓库地址：

https://github.com/laynefoley48-max/SillyTavern-CharacterShelf

已经安装的用户：直接在扩展管理器中更新插件并刷新 TT，不要卸载重装。

**注意：GitHub 仓库名称仍使用原来的 CharacterShelf，避免造成原有插件重复安装；界面显示名称已改为「角色备注」。原备注字段和 JSON 备份格式均不变。**

## v0.3.0 功能

- **列表**：角色左侧小头像，右侧名称和个人备注摘要。列表不显示原生标签。
- **迷你头像**：头像卡片宽度约缩为过去一半、面积约为过去的四分之一；头像下方角色名自适应换行，不截断。
- **统一详情**：点列表/头像卡片只打开完整个人备注和酒馆原生角色标签，底部有「编辑备注」「跳转卡面」两个按钮，只有点击跳转才切换角色。
- **排序**：默认按导入时间（date_added）新到旧，亦可旧到新、名称排序。
- **搜索**：角色名、个人备注及已有标签名称。
- **配色**：日间、灰色夜间、跟随酒馆主题；保留切换偏好。
- **扩展设置入口**：在「扩展」设置栏顶部添加「角色备注」面板，包含「打开角色备注」和「显示书本悬浮按钮」复选框。
- **魔法棒入口**：左下角魔法棒菜单新增「角色备注」。
- **可拖动的书本悬浮按钮**：默认关闭，开启后显示圆形书本图标，点击打开备注；拖动后记住位置，并跟随本插件选定的配色。
- **备份与恢复**：通过 JSON 备份和恢复私人备注。

## 数据兼容

私人备注依旧保存在 extension_settings.characterShelf.notes 中，以角色头像文件名区分；升级到 v0.3.0 不会主动迁移、重命名、清空备注。旧版 CharacterShelfBackup JSON 备份继续支持导入。

独立角色卡的原始作者备注、人设、世界书不会被修改，私人备注不会自动作为提示词发给 AI。只导出角色卡文件时，不会附带私人备注，所以重置 TT 前请先导出 JSON 备份。
