# 角色备注 · Character Notes

适用于 TauriTavern (TT) 与 SillyTavern (ST) 的角色卡私人备注与浏览扩展。

## 从 Git 安装或更新

扩展管理器 → 从 Git 安装 → 粘贴：

https://github.com/laynefoley48-max/SillyTavern-CharacterShelf

已安装的用户请直接在扩展管理器内更新并刷新酒馆，无须卸载重装。仓库名称暂时保留 CharacterShelf，避免改变已安装扩展目录；插件界面名称为「角色备注」。

## v0.4.1

- 微调列表卡片的视觉间距：角色名与备注摘要更紧凑，备注行高略微收紧，底部留白增加；列表功能和其他布局不变。
- TT/ST 单独更新扩展后可能需要手动刷新页面；这是宿主的更新机制，不由插件强制刷新。

## v0.4.0

- **紧凑界面：** 顶部只保留小标题、调色盘和关闭；搜索、简短排序与纯图标列表/头像切换处于同一排，显示区域更大。
- **备注筛选：** 全部（数量）/ 已备注（数量）/ 未备注（数量）三个并排按钮。搜索角色名、私人备注或原生标签后，计数跟随搜索条件更新。
- **配色：** 顶栏调色盘每单击一次循环「跟随酒馆 → 日间 → 灰色夜间 → 跟随酒馆」。新默认值为「跟随酒馆」。从 v0.3.0 升级的旧默认灰色首次切到跟随酒馆，后续会记住用户选择。
- **详情标签：** 显示角色全部原生标签（包括设置为隐藏的标签），没有原来的 40 个上限；单个标签保持单行，尽量占据可用宽度，过长时省略并保留悬停全文提示。标签换行排列成多行时，详情弹窗可以滚动。
- **原生折叠设置：** 扩展面板中「角色备注」采用 TT/ST 的 inline-drawer，默认折叠。点击标题展开，再点标题收起。展开后有「打开角色备注」、书本悬浮按钮开关、「备份备注」「恢复备注」。
- **列表视图：** 左侧小头像、右侧名字和私人备注摘要，不显示标签。
- **头像视图：** 迷你头像加自动换行的角色名字。
- **角色点击：** 先进入完整私人备注预览，再点「编辑备注」或「跳转卡面」。
- **其他入口：** 角色列表书本按钮、左下角魔法棒、可开关且可拖动的书本悬浮按钮。

## 隐私与数据存储

本插件不实现向第三方服务器主动上传角色卡、私人备注或浏览行为的功能。插件使用酒馆自己的 extension_settings 保存数据，保存位置取决于本地或远程酒馆运行方式，也可能受到用户额外配置的同步/备份机制影响。

私人备注继续保存于 extension_settings.characterShelf.notes，按角色头像文件名标识。升级到 v0.4.0 不修改备注存储键、不清空旧备注；旧 CharacterShelfBackup JSON 备份格式仍可以导入。

插件不会改动角色卡原始作者备注、人物设定或世界书，也不会将私人备注作为提示词发送给 AI。单独导出的角色卡文件不包含插件私人备注。重置酒馆、清空设置之前，请从扩展设置中导出 JSON 备份。
