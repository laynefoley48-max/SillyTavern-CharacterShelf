# 角色卡册 · Character Shelf

适用于 **TauriTavern (TT) / SillyTavern (ST)** 的独立前端扩展。为自己的角色卡添加私人备注，并用新的列表或头像网格快速浏览。

## 从 Git 安装

在 TT / ST 中打开 **扩展 → 安装扩展（Install extension from Git）**，粘贴：

https://github.com/laynefoley48-max/SillyTavern-CharacterShelf

安装完毕后重载酒馆。打开右侧「角色列表」，找到工具栏里的**书本图标**，点开角色卡册。

> 此版本依据 TauriTavern 源码进行开发，已上传标准扩展文件，但还没有在用户的实际 TT 环境中完成运行测试。若按钮未出现，请检查扩展管理器是否加载该扩展及控制台报错。

## 功能

- **列表视图**：左侧角色头像，右侧角色名字与私人备注摘要；长备注收起为 2～3 行。
- **头像网格**：小头像排列，名字在下方；有备注的角色以小圆点提示。
- **排序**：默认**按角色导入文件时间从新到旧**（字段 date_added）。另外支持旧到新、名字 A → Z 和 Z → A。缺少导入时间的角色排在末尾。
- **搜索**：同时搜索角色名和私人备注。
- **编辑**：点击铅笔直接给角色添加、修改或清空备注，支持超过 50 字。
- **打开角色**：点击角色卡本身，切换到对应角色。
- **备份**：可将私人备注备份为 JSON，也可以从 JSON 恢复。
- **界面**：独立的深蓝灰配色，兼容电脑及移动端。不会替换或改写酒馆自带的角色列表。

## 数据说明

备注保存于酒馆的扩展设置 extension_settings.characterShelf.notes。按每个角色当前头像文件名关联，而不是按角色名字关联。因此，同名但不同头像文件名的卡不会相互覆盖。角色重命名事件触发时会尽量迁移已有备注。

**私人备注不会写进角色卡人物设定或世界书，也不会自动发送给 AI。** 但将单独导出的角色卡文件传到其他酒馆时，私人备注也不会随卡转移；需要通过「备份备注」/「恢复备注」迁移。

**重置 TT、清空扩展设置前务必先备份私人备注。**

## 仓库结构

根目录必须直接包含：

- manifest.json — 扩展清单
- index.js — 角色浏览、排序、搜索、备注管理
- style.css — 独立界面样式
- README.md — 使用说明
